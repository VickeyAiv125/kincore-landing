# Kincore UAT Landing (demo)

Static “Page under construction” site for `uat.kincore.com`.

## Local preview

```bash
cd landing
python3 -m http.server 8080
# open http://localhost:8080
```

## Deploy

Copy contents of this folder to `/var/www/uat.kincore.com/` on the VPS (see full steps in chat / ops notes).
